# 0006 · 모델 기본값은 평가한 선택이 아니라 설정이다

- 상태: 채택
- 범위: 텍스트 모델과 이미지 모델

## 맥락

서비스의 기본값은 텍스트 `gpt-6-luna`, 이미지 `gpt-image-2.5-sunburst`다. 이 기본값은 개발 중에 정했고, 텍스트 기본값은 이전 모델에서 한 번 바뀌었다. 이 작업에서 후보 모델들을 같은 입력·프롬프트·출력 제한·검토자로 비교한 연구는 없다.

## 결정

- 두 모델은 문서에 기본값을 적은 환경변수 설정이다. 계약의 일부가 아니다.
- 응답은 모델 호출마다 모델 이름과 프롬프트 버전을 기록해, 결과를 설정까지 거슬러 올라갈 수 있게 한다.
- 문서는 어느 기본값도 패션 기획에 가장 좋은 선택이라고 주장하지 않는다.

## 결과

- 모델을 바꾸려면 설정 하나를 바꾸고, 오프라인 테스트와 작은 유료 검토 세트를 다시 돌린다.
- 모델 간 품질 차이는 알 수 없다. 공정하게 비교하려면 근거가 있는 고정 사례, 같은 프롬프트와 출력 제한, 어느 모델이 쓴 Draft인지 모르는 검토자가 필요하다.

## 검토한 대안

| 대안 | 지금 택하지 않은 이유 |
|---|---|
| 공개 전에 모델 비교 실행 | 프로젝트에 없던 유료 호출과 검토 시간이 필요하다. 이후 과제로 남긴다 |
| 모델을 코드에 고정 | 비용과 품질 결정을 코드 안에 숨긴다 |
